# recon 1.0, Phase 1 — Visible Bugs and Cheap Correctness

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the twelve phase 1 issues — everything a user meets today — so that the later phases start from a program with no known visible faults.

**Architecture:** Twelve independent tasks, one issue each. Nine change behaviour and get a test that fails first. Three (Task 1, Task 2, Task 5) cannot fail first, and each says why in its own steps. Tasks 5 and 6 share a file: Task 5 makes the seam that Task 6 tests through, so do them in order.

**Tech Stack:** Rust 2024 edition, ratatui 0.30.2, crossterm 0.29, `tui-textarea-2` (vendored fork), `regex`, `log`, `color-eyre`, `unicode-width`.

**Spec:** `docs/specs/2026-09-11-recon-1.0-release-design.md`

## Global Constraints

- Rust floor is **1.88**. Do not use a later feature.
- **No new dependency.** Every task uses a crate that `Cargo.toml` already names.
- CI must stay green. The three commands are exactly:
  - `cargo fmt -p recon --check`
  - `cargo clippy --workspace --all-targets -- -D warnings`
  - `cargo test --workspace`
- Commit messages follow the repository's conventional-commit style, for example `fix(picker): …`. Name the issue number in the body.
- Text that a user reads is written in ASD-STE100 Simplified Technical English.
- `log::warn!` is for a failure that changes what the user sees. `log::debug!` is for everything else.

fn restore_terminal() -> Result<()> {

/// `scan`, with a panic turned into a finished file.
///
/// `Scanner` keeps its own `Sender`, so a worker that panics never
/// disconnects the channel: `drain_scan_results`'s `Disconnected` warning
/// cannot fire, and the file stays `Unknown` for ever with nothing said. A
/// caught panic is reported as `eof: true` instead — the file is answered,
/// wrongly but finitely, and the navigator stops waiting (#188).
fn scan_caught(
    reader: impl BufRead,
    matcher: &Matcher,
    progress: Progress,
    cancel: &AtomicBool,

    let guarded = std::panic::AssertUnwindSafe(|| scan(reader, matcher, progress, cancel));
    match std::panic::catch_unwind(guarded) {
        Ok(progress) => progress,
        Err(_) => {
            log::warn!("a file's scan panicked; it is reported as read to the end");
            Progress {
                eof: true,
                ..progress
            }
        }
    }
}
